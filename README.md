# RedTech
# Business Intelligence & Data Analytics Projects

This repository contains the projects completed as part of my **EdVyro Internship**, covering data quality, data preprocessing, exploratory data analysis, statistical insights, business intelligence dashboards, and executive decision analytics.

## Projects Completed

### Task 1 – Data Quality & KPI Framework
- Performed data profiling, data quality checks, missing-value analysis, duplicate detection and validation using **Python, Pandas and NumPy**.
- Identified data quality issues related to completeness, uniqueness, validity and consistency.
- Defined important business KPIs including **Revenue, Total Orders, Units Sold, Average Order Value and Refund Rate**.
- Created a **Data Quality Contract** with quality rules, thresholds, ownership and escalation actions.

### Task 2 – Data Ingestion, Cleaning & Preprocessing
- Loaded and processed a real-world retail dataset using **Python and Pandas**.
- Handled missing values, duplicate records, incorrect data types and inconsistent categorical values.
- Detected and treated numerical outliers using the **IQR method**.
- Performed feature engineering including **Order Year, Order Month, Profit Margin and Shipping Days**.

### Task 3 – Exploratory Data Analysis & Statistical Insights
- Conducted comprehensive **Exploratory Data Analysis (EDA)** using Pandas, NumPy and Matplotlib.
- Analyzed revenue, quantity, unit price, countries, products and monthly sales trends.
- Performed correlation analysis and statistical hypothesis testing using **SciPy**.
- Generated business insights from customer purchasing behavior, revenue patterns and transaction data.

### Task 4 – Interactive Dashboard & KPI Visualization
- Built an interactive **Executive Business Dashboard using Power BI**.
- Created KPI cards for **Total Revenue, Customer Acquisition Cost, Churn Rate and Average Order Value**.
- Added revenue trends, acquisition-channel analysis, geographic visualization, churn analysis and interactive slicers.
- Implemented **temporal and categorical drill-downs** including Year → Quarter → Month and Country → City.

### Task 5 – Executive Decision Report & Capstone Presentation
- Synthesized analytical findings into an **executive-ready business decision report**.
- Analyzed revenue drivers, customer acquisition, churn risks, customer lifetime value and marketing efficiency.
- Developed **3 strategic business recommendations** supported by data-driven insights.
- Created **ROI projections and an implementation roadmap** for actionable business decision-making.
